Fire TV — Live TV Web Player

A browser-based live TV player for discovering and watching publicly listed television streams. Browse channels by country and genre, search for channels, save favorites, and use the built-in video player.

Features

- Live TV playback in a modern web interface
- Search channels by name, country, and genre
- Filter and sort available channels
- Save favorite channels
- View recently selected channels
- Support for HLS video streams where compatible with the browser
- Responsive interface for mobile and desktop screens
- Fullscreen and other available video playback controls

Feature availability depends on browser compatibility and the stream itself.

Getting Started
Use the online player

Open the live page:

https://firetv-six.vercel.app/

Choose a channel from the available list to attempt playback.

Run locally

1. Clone this repository.
2. Open the project directory.
3. Serve "index.html" using a local HTTP server.
4. Open the local URL in a modern web browser.

The application uses a publicly accessible IPTV playlist and the HLS.js JavaScript library. Playback depends on stream availability, browser support, network access, and the relevant stream provider's configuration.

Technology
